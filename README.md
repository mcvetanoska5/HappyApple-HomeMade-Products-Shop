🍎 Happy Apple – Homemade Products Shop

Happy Apple is a web application for presenting and promoting homemade products from a family-owned orchard in Prespa, North Macedonia. The project aims to bring traditional, homemade products closer to customers through a modern, user-friendly online shopping experience.

The website highlights the story behind the family business, its products, and the values of quality, tradition, and homemade production.

✨ Features

Product Showcase – Present homemade products in an organized and attractive way.

About Us – Introduce the family business, its history, and the people behind Happy Apple.

Responsive Design – Provide a convenient browsing experience across desktop, tablet, and mobile devices.

Modern User Interface – Use a clean layout and a warm visual identity inspired by homemade products and the Prespa region.

Product Information – Help visitors discover products and learn more about the business.

🛠️ Technologies Used

React – Building the user interface with reusable components.

Supabase – Supporting the application's connected backend services and data management.

JavaScript – Implementing application functionality.

HTML5 & CSS3 – Structuring and styling the website.

Git & GitHub – Version control and project collaboration.

🚀 Getting Started

Follow these steps to run the project locally.

Prerequisites

Make sure you have installed:

Node.js

npm (included with Node.js)

Git

Installation

Clone the repository:

git clone https://github.com/mcvetanoska5/HappyApple-HomeMade-Products-Shop.git

Navigate to the project directory:

cd HappyApple-HomeMade-Products-Shop

Install the dependencies:

npm install

Start the development server:

npm run dev

Open the local URL displayed in the terminal to view the application.

Note: If the project uses environment variables for Supabase, configure them according to the project's existing setup before starting the application. Never commit secret keys or private credentials to GitHub.

🌱 Project Purpose

Happy Apple was created to establish an online presence for a family business focused on homemade products. By combining a personal family story with a modern web interface, the project demonstrates how web technologies can help small businesses present their products and connect with potential customers.
